# описание проверок
Группа и номер по журналу: Т118, 5

Назначение: Программа помогает разделить общую стоимость между участниками для учебной поездки.

Команда запуска: python main.py

Ограничения ввода: Целое число 
Минимум: 0 (для стоимости)
Минимум: 1 (для участников)

Отклонение: буквы, пустая строка, отрицательные числа. дробные.
При отклонении: повторять ввод

Пример работы: Стоимость поездки, тенге: 12000
Количество участников: 6
С каждого участника: 2000.0 тенге
