# Списки Python
Группа: Т118, 5

Назначение:
Учебная работа по теме «Списки в Python»: индексы и срезы, методы списка,
ввод и проверка значений, статистика, фильтрация, исправление элемента
по номеру, копирование вложенных списков.

Запуск:
python task2.py
python task3.py
python main.py
python task8.py

main.py запрашивает 5 оценок (0-100), выводит статистику и список на
пересдачу, затем запрашивает номер оценки и новое значение.
